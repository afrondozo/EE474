◆ lightDetector()

void lightDetector ( void * arg)

FreeRTOS task that reads the photoresistor value and computes a 5-sample Simple Moving Average (SMA).

Reads the current light level, updates the circular buffer, computes the SMA, waits 500 ms, and then signals other tasks via a semaphore that new data is available.
